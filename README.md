<h2>📌 Visão Geral</h2>

<p>
O WarpZone é uma plataforma web que permite aos usuários jogar games clássicos retrô diretamente pelo navegador, sem necessidade de instalação de emuladores ou arquivos adicionais.
</p>

<p>
O site utiliza o EmulatorJS, possibilitando a emulação de diversos consoles antigos de forma online, oferecendo acessibilidade, praticidade e preservação digital de jogos clássicos.
</p>


<h2>🎯 Objetivo do Projeto</h2>

<p>O objetivo do WarpZone é:</p>

<ul>
  <li>Disponibilizar jogos clássicos em ambiente web</li>
  <li>Facilitar o acesso a games retrô</li>
  <li>Eliminar a necessidade de instalação local de emuladores</li>
  <li>Proporcionar experiência nostálgica diretamente no navegador</li>
  <li>Demonstrar o uso de tecnologias web aplicadas à emulação</li>
</ul>


<h2>🕹️ Funcionalidades</h2>

<ul>
  <li>✅ Execução de jogos clássicos no navegador</li>
  <li>✅ Interface simples e intuitiva</li>
  <li>✅ Suporte a múltiplos consoles</li>
  <li>✅ Carregamento dinâmico de ROMs</li>
  <li>✅ Controles via teclado ou controle USB</li>
  <li>✅ Sistema totalmente web-based</li>
</ul>
