📌 Visão Geral

O WarpZone é uma plataforma web que permite aos usuários jogar games clássicos retrô diretamente pelo navegador, sem necessidade de instalação de emuladores ou arquivos adicionais.

O site utiliza o EmulatorJS, possibilitando a emulação de diversos consoles antigos de forma online, oferecendo acessibilidade, praticidade e preservação digital de jogos clássicos.

🎯 Objetivo do Projeto

O objetivo do WarpZone é:

Disponibilizar jogos clássicos em ambiente web

Facilitar o acesso a games retrô

Eliminar a necessidade de instalação local de emuladores

Proporcionar experiência nostálgica diretamente no navegador

Demonstrar o uso de tecnologias web aplicadas à emulação

🕹️ Funcionalidades

✅ Execução de jogos clássicos no navegador
✅ Interface simples e intuitiva
✅ Suporte a múltiplos consoles
✅ Carregamento dinâmico de ROMs
✅ Controles via teclado ou controle USB
✅ Sistema totalmente web-based
